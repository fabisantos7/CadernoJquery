Capítulo 01 — fundamento

O que é o $(), afinal?

O $ é só um apelido para a função jQuery(). Ela faz uma coisa só, brilhante: embrulha qualquer coisa e devolve um objeto cheio de superpoderes.

O objeto que sai de $() é array-like: parece uma lista (tem .length, e você pega um item com [0]), mas vem com dezenas de métodos prontos. É por isso que dá para escrever $('.x').addClass('y') — você está chamando um método na lista inteira de uma vez.

// As 4 formas de chamar $() — todas aparecem no main.js:
$('#modal-name')          // 1. seletor CSS → pega elemento(s) da página
$(el)                    // 2. node nativo → re-embrulha (setPhoto recebeu this)
$('<div class="toast">')  // 3. string HTML → CRIA elemento novo em memória
$({v:0})                 // 4. objeto comum → animável! (capítulo 10)

// array-like: lista de nodes com métodos em cima
$('.r-row').length       // → 8 (quantos achou)
$('.r-row')[0]           // → o node DOM puro, sem superpoderes

// ▸ DOCUMENT READY: roda quando o HTML terminou de carregar.
//   É o envelope de TODO o main.js.
$(function(){ /* ...todo o site... */ });
Regra de ouro do projeto

jQuery orquestra, CSS executa. O JS decide quando (adiciona/remove classes), o CSS decide como (as transitions). O que escapa disso está marcado: .animate() e o loop do cursor.

Capítulo 02 — encontrar

Seletores: encontrar antes de agir

Todo método jQuery começa com uma pergunta: em quem? O seletor é sintaxe CSS pura — se você sabe CSS, já sabe selecionar.

Os que o site usa: #id (um), .classe (vários), a[href^="#"] (atributo que começa com), .reveal:not(.in) (menos os que já têm a classe), #a, #b (lista) e [data-slot] (tem o atributo). E o truque de escopo: $('#pai').find('.filho') busca só dentro do pai.

// do main.js — repare nos 4 estilos diferentes:
$('a[href^="#"]')        // todo link-âncora (cap. 7)
$('.reveal:not(.in)')    // quem AINDA não entrou na tela
$('#cursor-dot, #cursor-ring').remove() // dois de uma vez
$('.js-photo[data-slot]') // imgs que têm o atributo

Capítulo 03 — o conceito mais importante

Eventos & delegação

.on('click', fn) conecta um evento a um elemento. Fácil. O assunto sério é outro: e quando o elemento nascer DEPOIS?

No site, as 8 linhas do índice nascem via .html() — ou seja, não existiam quando a página carregou. Um bind direto nelas seria em vão. A delegação resolve: você escuta o pai e passa um "filtro". Quando o clique borbulha do filho até o pai, o jQuery checa se o alvo bate com o filtro. Um único listener serve para os filhos de hoje e de sempre.

// ❌ bind direto — rodou ANTES das linhas existirem: não pega nada
$('.r-row').on('click', fn)

// ✔ DELEGAÇÃO — o #recipe-list (pai) escuta por todas as .r-row,
//   as de hoje e as de amanhã. Sintaxe: .on(evento, filtro, fn)
$('#recipe-list').on('click', '.r-row', function(){
  // $(this) = a linha específica clicada
  openRecipe($(this).data('id'));
})

// extras que o site usa:
e.stopPropagation()  // não deixe o clique subir (salvar ≠ abrir)
$img.one('load', fn) // dispara UMA vez e se desliga sozinho

Capítulo 04 — mudar

Manipulação de DOM

Ler e escrever conteúdo, atributos e dados — o dia a dia do openRecipe(), que enche o modal inteiro com seis chamadas seguidas.

.html() escreve HTML (interpreta tags); .text() escreve texto puro (mostra as tags). .attr() e .val() têm a dualidade getter/setter: sem argumento leem, com argumento escrevem. .data() conversa com os atributos data-*. .append() anexa, .remove() apaga de verdade.

// trecho real do openRecipe() no main.js:
$('#modal-img').attr('src', foto)     // setter: troca a foto
$('#modal-name').text(r.name)         // setter: escreve o título
$('#modal-ingredients').html(lista)   // setter: injeta os <li>
const v = $('#nl-email').val()        // getter: lê o input
const id = $(this).data('id')         // getter: lê data-id
$('#preloader').remove()              // tira do DOM de verdade

Capítulo 05 — o motor do site

Classes: ligar e desligar estados

Se o site "anda", é por aqui. addClass / removeClass / toggleClass alternam classes de estado que o CSS transforma em movimento — modal abre, drawer desliza, linha salva fica terracota.

Dois padrões para gravar: o par "aba ativa" (remove de todos, adiciona no clicado) e o toggle com boolean — o 2º argumento decide, virando um "if" de uma linha. O refreshSaveButtons() do site usa isso para sincronizar os 8 botões de salvar com o caderno.

// padrão "aba ativa" — usado nos filtros de região:
$('.filter-btn').removeClass('active')  // apaga TODOS
$(this).addClass('active')              // acende o CLICADO

// toggle CONDICIONAL — o boolean manda:
$('#site-nav').toggleClass('scrolled', st > 40)
$(this).toggleClass('saved', notebook.includes(id))

Capítulo 06 — mover

Efeitos & animação

O jQuery anima propriedades numéricas por frame: .animate({left, opacity}, duração). Para o resto (cores, transforms), o site usa transições CSS — e o jQuery só dispara.

Os dois superpoderes daqui: o callback (o código roda quando a animação termina — é assim que o fadeOut do formulário encadeia a mensagem de sucesso) e o .stop(true, true) (limpa a fila e termina a atual na hora — sem ele, cliques rápidos empilham animações "moles").

// sequenciamento com callback — trecho real da newsletter:
$('#nl-form').fadeOut(200, function(){
  $('#nl-success').addClass('show')  // roda DEPOIS do fade
})

// entrada em cascata dos filtros (com o PATCH P2 aplicado):
$r.addClass('in').css({display:'', opacity:0, transition:'none'})
  .animate({opacity:1}, 320, function(){ $r.css('transition','') })

Capítulo 07 — medir

Medidas & scroll

Barra de leitura, reveals, contadores, âncoras suaves — tudo começa com geometria: onde estou, onde a página termina, onde o elemento está.

Atenção à dualidade: .scrollTop() sem argumento lê a posição da rolagem; .scrollTop(0) vai até a posição (o modal usa isso para resetar). E .offset().top é a distância do elemento ao topo do documento — o número exato que o scrollTop precisa para chegar lá.

// a âncora suave — técnica clássica (main.js, "ÂNCORAS SUAVES"):
$('a[href^="#"]').on('click', function(e){
  const href = $(this).attr('href')
  if(href.length > 1 && $(href).length){      // destino existe?
    e.preventDefault()                          // cancela o salto bruto
    $('html,body').animate(
      { scrollTop: $(href).offset().top - 55 }, 850)  // -55: nav fixa
  }
})
// 'html,body' cobre navegadores que animam um OU outro
Performance

O scroll dispara dezenas de vezes por segundo. O site usa a flag ticking + requestAnimationFrame: no máximo 1 cálculo por frame. Guarde esse par.

Capítulo 08 — falar com o mundo

AJAX & promises

É o sistema de fotos do site. $.ajax() pede dados a um servidor e devolve uma promise — um "recibo" com promessa de valor: .done() quando chega, .fail() se der errado, .always() em qualquer caso.

O $.when(p1, p2, …) espera várias promises ao mesmo tempo. Como as nossas vivem num array, usamos $.when.apply($, jobs) para espalhá-las como argumentos. E o $.Deferred() cria uma promise nossa — o site resolve todas as fotos e só então avisa o resto do código com .then().

// FONTE A do sistema de fotos (main.js) — em lote:
$.ajax({
  url: 'https://pt.wikipedia.org/w/api.php', dataType: 'json',
  data: { action:'query', format:'json', origin:'*', // origin:* = libera CORS
          prop:'pageimages', pithumbsize:1200,
          titles: 'Vatapá|Tacacá|Barreado' }  // lote: 1 requisição
}).done(function(resp){ /* parseThumbs extrai as URLs */ })
  .fail(function(){ /* segue com os fallbacks */ })

// blindagem: uma API cair não derruba as outras
jobs.map(j => j.then(d => d, () => null))

Capítulo 09 — estilo de escrita

Encadeamento: a assinatura do jQuery

Quase todo método jQuery devolve o próprio objeto — por isso dá para emendar um atrás do outro como contas de matemática.

No site isso aparece em toda parte, mas o campeão é o botão de salvar do modal: três operações em uma expressão. Ler encadeamento tem um truque: leia da esquerda para a direita, cada elo fala com o resultado do anterior.

// main.js — syncModalSave(): três métodos, uma linha:
$('#modal-save')
  .toggleClass('is-saved', saved)  // 1. estado visual
  .data('id', id)                  // 2. grava qual receita sou (setter!)
  .html(interno)                   // 3. troca o conteúdo do botão

// e o setPhoto() devolve $img justamente para permitir:
setPhoto($('#modal-img'), src, fb).attr('alt', nome)

Capítulo 10 — nível avançado

Truques de mestre

① O objeto fantasma. O .animate() não precisa de elemento! Ele anima números de qualquer objeto. O site cria $({v:0}) e anima até 142 — o callback step roda a cada frame escrevendo o valor no HTML. É assim que os contadores do manifesto funcionam.

② Quando o jQuery NÃO serve. O evento error das imagens não borbulha — e a delegação depende de borbulhamento. Por isso o fallback de fotos é um listener nativo em capture phase (o true de 3º argumento intercepta na descida). Saber a hora de trocar de ferramenta faz parte.

// ① objeto fantasma (main.js, contadores):
$({v:0}).animate({v: target}, {
  duration: 1600, easing: 'swing',
  step: function(now){ $el.text(Math.round(now)) },  // a cada frame
  complete: function(){ $el.text(target) }
})

// ② capture phase — error não borbulha, delegação não pega:
document.addEventListener('error', function(e){
  // consome o próximo fallback da fila data-fallbacks
}, true)  // ← true = CAPTURE (intercepta na descida)
Divisão de trabalho no projeto

jQuery: seletores, eventos, DOM, classes, .animate, AJAX. Nativo: requestAnimationFrame, localStorage, matchMedia, Array/String methods, o listener de error. Nenhum é "melhor" — são parceiros.
